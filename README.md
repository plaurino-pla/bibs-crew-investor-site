# Bib's Crew — Investor Site

Investment opportunity one-pager for the acquisition of Bib's Crew, a specialty-coffee café in Paço de Arcos, Oeiras (June 2026).

Single static page (`index.html`) with an interactive 3-year P&L model built on Chart.js. No build step.

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

## Data room

Source documents (official tax filings, trial balances, clearance certificates, lease, payroll) are **not** in this repository — they contain personal and fiscal data. Access is granted on request via the contact on the site.
